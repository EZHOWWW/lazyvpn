# lazyvpn

TUI-утилита на Rust для Linux, которая агрегирует и удобно переключает все VPN на машине
(подписочные VPN, `openfortivpn`, proxy и другие) в одном интерфейсе в стиле lazygit / lazydocker.

## Agent skills

### Issue tracker

Issues и спеки живут в GitHub Issues репозитория `EZHOWWW/lazyvpn` (через `gh` CLI). См. `docs/agents/issue-tracker.md`.

### Triage labels

Стандартный набор из пяти канонических ролей (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). См. `docs/agents/triage-labels.md`.

### Domain docs

Single-context: один `CONTEXT.md` и `docs/adr/` в корне репозитория. См. `docs/agents/domain.md`.
